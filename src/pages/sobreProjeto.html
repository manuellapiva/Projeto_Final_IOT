PROJETO DE INTERNET DAS COISAS

Estação Climática em Tempo Real

Um projeto desenvolvido para utilizar a tecnologia da Internet das Coisas no monitoramento de condições ambientais através de sensores conectados à internet.

Conheça o projeto →
01 — OBJETIVO

Qual é a proposta do projeto?

O objetivo deste projeto é desenvolver uma estação de monitoramento ambiental utilizando conceitos de Internet das Coisas (IoT).

Através de sensores conectados a um ESP32, o sistema realiza a coleta de informações sobre o ambiente, como temperatura, umidade e qualidade do ar.

Esses dados são enviados através de uma rede Wi-Fi para um servidor MQTT e posteriormente apresentados em um dashboard, permitindo acompanhar as informações em tempo real.
